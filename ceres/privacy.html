概要

ケレス（以下「本アプリ」）は、ERU CLARISSA が開発した、利用者が自分で記録した買い物の値段を、公的な価格データと並べて表示するアプリです。このポリシーでは、本アプリが扱う情報と、その扱い方を説明します。本アプリはアカウント登録が不要で、利用者が入力した記録を開発者やほかの誰にも送信しません。

端末に保存する情報

本アプリは、次の情報を利用者の端末の中だけに、ほかのアプリから読めない場所に保存します：利用者が作ったカテゴリと商品（名前・単価のそろえ方・紐づけた品目）、値段の記録（日付・お店の名前・価格・内容量・メモ）、住んでいる所として選んだ市区町村、比べる調査市、取得した公的な価格データの写し。これらのうち、値段の記録・商品・カテゴリ・市区町村は送信されません。本アプリをアンインストールするか、アプリのデータを消去すると削除されます。

通信（公的な価格データの取得）

本アプリは、公的な価格データ（総務省統計局・農林水産省の公表データを開発者が加工したもの）を表示するため、アプリを開いたときなどに、開発者が GitHub Pages（GitHub, Inc. が運営するウェブの配信サービス、eru-clarissa.github.io）に置いたファイルを取得します。このとき、次の情報が通信の仕組み上、GitHub に送られます。

  • 取得するファイルの名前。比べる調査市のデータのファイル名には、その調査市のコード（例：東京都区部を表す 13100）が含まれます。調査市は、利用者が選んだ市区町村の近くの市を本アプリが選んだもので、利用者が住んでいる市区町村そのものではないことがあります。
  • IP アドレス、端末やアプリの種類など、インターネットの通信で一般に送られる情報。

これらは GitHub のプライバシーに関する方針に従って扱われます。開発者は GitHub Pages のアクセスの記録を受け取っておらず、利用者を特定する目的でこれらの情報を使うことはありません。通信では、ファイルを取得するだけで、利用者の記録や設定を送ることはありません。インターネットにつながっていないときは、前回取得したデータを表示します。

位置情報

本アプリは、端末の位置情報（GPS など）を使いません。住んでいる所は、利用者が都道府県と市区町村を一覧から選びます（選ばずに使うこともできます）。

バックアップのファイル

「記録を書き出す」を使うと、記録・商品・カテゴリ・選んだ市区町村を含むファイルを作り、Android の保存画面で利用者が選んだ場所（端末のフォルダやクラウドのドライブなど）に保存します。「記録を読み込む」では、利用者が選んだファイルだけを読み取ります。保存先での扱いは、その保存先のサービスのポリシーに従います。本アプリは、端末のファイルをまとめて読む権限を持ちません。

外部のリンク

このポリシーなどのリンクを開くと、利用者の端末のブラウザで外部のページが開きます。開いたあとの情報の扱いは、そのページのポリシーに従います。

広告

現在の版の本アプリは、広告を表示せず、広告 ID も使いません。今後の版で広告を入れる場合は、その版を公開する前にこのポリシーを更新し、広告の提供元、扱う情報、利用者が選べることを説明します。

情報の提供・販売

開発者は、利用者の個人情報を販売したり、第三者に提供したりしません。

表示するデータについて

本アプリが表示する公的な価格データは、総務省統計局「小売物価統計調査」、農林水産省「食品価格動向調査」「野菜の生育状況及び価格見通し」「今週のお手頃野菜」などの公表データを加工したものです。各機関が作成したものではなく、内容は各機関の公表資料が正です。このサービスは、政府統計総合窓口(e-Stat)のAPI機能を使用していますが、サービスの内容は国によって保証されたものではありません。

子どもの利用

本アプリは13歳未満の子どもを対象としておらず、開発者が子どもの個人情報を意図して収集することはありません。

このポリシーの変更

本アプリの機能や情報の扱いが変わったときは、このポリシーを更新します。最新の内容は、最終更新日とともにこのページに掲載します。
